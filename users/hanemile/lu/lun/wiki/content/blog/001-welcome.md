# Welcome to My Wiki

This is my personal wiki built entirely in **Lun**, a Lisp-like language!

The wiki system demonstrates several features:
- Dynamic page generation
- Blog post listing
- Project showcases
- Pure functional programming

This wiki is a testament to the power of minimal, elegant code. Every page you see is generated from simple Lun functions that read markdown files and transform them into HTML.

## Why Lun?

Lun is a beautiful, minimal Lisp dialect that focuses on:
- Simplicity
- Functional purity
- Expressive power

Building this wiki in Lun was a fun exercise in pushing the boundaries of what's possible with a minimal language implementation.
