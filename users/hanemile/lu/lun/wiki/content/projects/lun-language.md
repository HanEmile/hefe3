# Lun Language

A minimal, elegant Lisp dialect implemented in Rust.

## Features

- Clean syntax
- Functional programming
- Easy to extend
- Fast execution

## Why Lun?

Lun was created to explore the essence of Lisp while maintaining modern performance characteristics through Rust.
