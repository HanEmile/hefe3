# Scheme Compiler

A Scheme-to-C compiler for high-performance functional programming.

## Goals

- Compile Scheme to efficient C code
- Support full R5RS standard
- Optimize tail calls
- Generate readable C output

## Status

Currently in active development. Core features working, optimizations in progress.
