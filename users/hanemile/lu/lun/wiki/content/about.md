# About Me

Hi! I'm Emile, a passionate programmer exploring the beautiful world of functional programming and language design.

## Interests

- **Functional Programming**: Lisp, Scheme, Haskell
- **Language Implementation**: Interpreters, compilers, VMs
- **Minimalism**: Elegant, simple solutions
- **Open Source**: Contributing to the community

## Philosophy

I believe in the power of simple, composable abstractions. The best code is often the code that does the least while achieving the most.

## This Wiki

This wiki is built entirely in Lun, a minimal Lisp dialect I've been developing. It's a practical demonstration of functional programming principles applied to a real-world problem.

## Contact

Feel free to reach out if you want to discuss functional programming, language design, or collaborate on interesting projects!
