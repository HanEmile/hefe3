# order

A lisp-powered personal wiki and knowledge management system.

## Features

- Markdown-like syntax that's actually Lisp
- Query language for dynamic content
- Backlinks and cross-references
- Tiered access control
- Static site generation

## Tech

Written in Common Lisp using SBCL.
